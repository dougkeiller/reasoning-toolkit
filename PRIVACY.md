# Privacy policy: reasoning-toolkit

Last updated: 2026-11-24

reasoning-toolkit is an open-source plugin of instructions for Claude. The author runs no server and no service for it, and receives, collects, stores and shares no data from anyone who uses it.

It reads only what you give it in your Claude session. Some skills write a small JSON spec to your workspace to run a calculation.

Anything you send to Claude is handled under Anthropic's own terms and privacy policy, not by this plugin's author.

Questions: open an issue at https://github.com/dougkeiller/reasoning-toolkit/issues.
